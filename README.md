# Lizarco Price Alert

اپ اندروید برای انتخاب محصولات لیزارکو و هشدار تغییر قیمت.

## ساخت APK بدون Android Studio
این پروژه Workflow آماده GitHub Actions دارد.

1. کل محتویات این پوشه را داخل Repository گیت‌هاب قرار دهید.
2. به تب **Actions** بروید.
3. Workflow با نام **Build Android APK** را باز کنید.
4. روی **Run workflow** بزنید.
5. پس از پایان موفق، اجرای Workflow را باز کنید.
6. از بخش **Artifacts** فایل `LizarcoPriceAlert-debug-apk` را دانلود کنید.
7. ZIP دانلودشده را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## نکته
- برنامه برای بررسی قیمت، شبکه لازم دارد.
- بررسی دوره‌ای با WorkManager روی فاصله 12 ساعت تنظیم شده؛ اندروید ممکن است اجرای دقیق را به دلیل بهینه‌سازی باتری کمی جابه‌جا کند.
- اعلان‌ها در Android 13+ نیاز به اجازه Notifications دارند.
- سایت فعلی لیزارکو از لینک‌های `/product-detail/...` استفاده می‌کند و برنامه همین الگو را برای دریافت محصولات هدف می‌گیرد.
